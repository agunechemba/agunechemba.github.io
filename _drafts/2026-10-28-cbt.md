# CBT — Computer-Based Testing Platform

A self-hosted CBT platform with **server-authoritative grading**, live webcam/mic **proctoring**, and database. The answer key never reaches the candidate's browser.

**Live demo:** [agunechemba.name.ng/cbt](https://agunechemba.name.ng/cbt/)

---

## Features

- **🔐 Server-side grading** — Correct answers stay on the backend
- **📊 Google Sheets backend** — No database to manage
- **🎥 Live proctoring** — Webcam motion + microphone sound detection
- **🎫 Single-use entry codes** — Server marks codes as used after submission
- **⏱️ Server-enforced timer** — Late submissions rejected
- **🧮 Built-in calculator** — Draggable widget for candidates
- **📱 Responsive UI** — Side-by-side on desktop, stacked on mobile
- **🔍 Full audit trail** — Per-question choices logged as JSON
