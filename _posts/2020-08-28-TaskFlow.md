# TaskFlow: Professional To-Do

A minimalist, mobile-first *task management* PWA with hourly reminders and automatic dark/light theme adaptation.

## ✨ Features

- Gentle notifications every hour (at :00) reminding you of incomplete tasks
- Install as a standalone app on Android, iOS, and desktop
- Adapts to your system's light/dark mode
- Tasks survive browser refreshes and device restarts
- Add, complete, and filter tasks by Active, Completed, or All
- See exactly when tasks were marked complete
