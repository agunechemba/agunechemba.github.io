# 🐍 PPH Learners Playground (Python)

A browser-based Python IDE with syntax highlighting, theming, and code execution using Pyodide.

## Features

- ✅ **Write & Run Python**
- ✅ **Syntax Highlighting**
- ✅ **Dark/Light Theme**
- ✅ **Download Code**
- ✅ **Line Numbers**
- ✅ **Keyboard Shortcuts(Ctrl+Enter)**
- ✅ **Responsive Design**


## Technologies

- **Pyodide**
- **CSS Custom Properties**
- **Vanilla JavaScript**

## Theme Toggle

The theme cycles through:
- **🌓 Auto**
- **☀️ Light**
- **🌙 Dark**
