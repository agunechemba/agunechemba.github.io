# 🟨 JS Console · PPH Playground

A browser-based JavaScript console with syntax highlighting, theming, and code execution.

## Features

- ✅ **Write & Run JavaScript**
- ✅ **Syntax Highlighting** (JavaScript flavored)
- ✅ **Dark/Light Theme** (auto, manual toggle)
- ✅ **Download Code** as `.js` file
- ✅ **Line Numbers**
- ✅ **Keyboard Shortcut** (`Ctrl+Enter` / `Cmd+Enter`)
- ✅ **Responsive Design**
- ✅ **Async/Await Support** (top-level await supported)
- ✅ **Console Output Capture** (logs, errors, warnings)
