A web application that helps you discover ancestral market days based on traditional African calendars (Igbo and Yoruba). The app calculates market days using a reference date system and provides a beautiful, responsive interface with dark/light theme support.

Features

  • Support for Igbo and Yoruba traditional calendars
  • Calculate ancestral market days from any Gregorian date
  • Automatic dark/light mode with manual toggle
  • Works on all screen sizes
  • Smooth animations and visual feedback
  • Respects user's system theme settings

Calendar Reference

  • Igbo: Eke, Orie, Afor, Nkwo
  • Yoruba: Ọjọ́ Ifá, Ọjọ́ Ọ̀rìṣà, Ọjọ́ Ọ̀ṣun, Ọjọ́ Ẹ̀bọra
