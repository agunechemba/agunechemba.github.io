Here is how I built a secure CBT platform from scratch. 🚨

Tired of candidates inspecting the page source to find the answers?

I built a Computer-Based Testing (CBT) platform that keeps the answer key completely hidden on the server.

Here is what makes this build special:

  • 🔐 Server-Authoritative Grading: The browser never sees the correct answers.
  • 📊 Google Sheets Backend: No complex SQL database to manage.
  • 🎥 Live Proctoring: Detects motion via webcam and sound via microphone.
  • ⏱️ Server-Enforced Timer: No cheating the clock—late submissions are rejected.
  • 🎫 Single-Use Codes: Entry codes expire the moment a student submits.

This project combines security, UI design (check out the built-in draggable calculator! 🧮), and backend logic to create a real-world solution.
