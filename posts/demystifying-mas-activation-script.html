If you’ve ever searched for a way to activate Windows or Microsoft Office, you’ve likely stumbled across the Microsoft Activation Scripts (MAS). In this guide, we’ll break down exactly what this tool does, where to run the code, and what happens when you navigate its menu.

Disclaimer: Using MAS is considered software piracy and bypasses official licensing. While it is widely used by home users, it is not legal and carries security risks. For a completely safe and legal experience, purchasing an official license is recommended.

Let’s walk through it like a story, step by step.

Step 1: Opening the Right Window

First, you need to know where to type the code. You cannot run this in the standard Command Prompt (CMD). You must use PowerShell with Administrator privileges.

How to do it:

First, right-click the Start Button (or press Win + X).
Second, select "Windows PowerShell (Admin)" on Windows 10 or "Terminal (Admin)" on Windows 11.
Third, click Yes if a User Account Control (UAC) prompt appears.

Step 2: Running the Command

Once your blue PowerShell window is open, you need to paste the activation command. Copy and paste this exact code into the window and press Enter:

irm https://get.activated.win | iex

What this does:
The irm stands for "Invoke-RestMethod," which downloads the script from the internet.
The iex stands for "Invoke-Expression," which executes the downloaded script immediately.

(Note: Always double-check the URL spelling. Fake domains like get.activate[.]win exist and distribute malware.)

Step 3: Navigating the Activation Menu

After the code finishes downloading, the screen will clear and present you with a menu. You might also see a green link pointing to massgrave.dev—this is just the official help page for the script.

Here is the breakdown of the main options:

[1] HWID: Activates Windows 10 or 11 permanently.
[2] Ohook: Activates Microsoft Office permanently.
[3] TSforge: An alternative method for older versions of Windows/Office.
[4] Online KMS: A temporary activation that requires renewal every 180 days.
[5] Check Activation Status: Shows you what is currently activated.
[0] Exit: Closes the program.

Step 4: What Happens When You Click [1]?

If you are here to activate Windows, typing 1 and pressing Enter is your best bet.

Here is exactly what happens next:

First, the script initiates the HWID (Hardware ID) process.
Second, it generates a ticket and contacts Microsoft's servers to request a digital license.
Third, if successful, the text on your screen will turn green, indicating the activation was completed.
Finally, you will be prompted to press any key to return to the main menu, where you can press 0 to exit.

How it works

Clicking [1] grants your computer a permanent digital license. This license is permanently linked to your computer's motherboard. This means that if you ever need to do a clean reinstall of Windows in the future, it will automatically reactivate as soon as you connect to the internet.

Requirements for Option 1:
You must have an active internet connection.
Your Windows version must match (e.g., Windows 10 or 11).

Step 5: Verifying Your Activation

Once the script says it is successful, you can close the PowerShell window. To confirm the activation worked:

First, open Windows Settings.
Second, go to System > Activation.
Third, you should see a message saying "Windows is activated with a digital license linked to your Microsoft account."

For Microsoft Office, simply open an app like Word, go to File > Account, and check the "Product Information" section.
