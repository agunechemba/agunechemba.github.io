Welcome to the official source code repository for the Clasam Schools website project. This website serves as the primary digital presence for Clasam Schools, highlighting its history, academic programs, core values, and contact information.

📌 Project Overview

The Clasam Schools website is a lightweight, responsive multi-page web application designed to present prospective and returning parents with key information about the school. Built using vanilla web development technologies, it features an interactive interface, smooth scroll-triggered animations, hero image sliders, interactive statistics counters, and an intuitive contact pathway.

✨ Features & Functionality

🌐 Pages

  1. Home (index.html):
    • Dynamic Hero Image Slider with touch/swipe support.
    • Core values, mission, and vision overview cards.
    • Educational levels overview (Early Years, Junior School, Senior School).
    • Parent testimonials section.
    • Animated statistical achievements counter.
  2. Founder's Message (founder.html):
    • Detailed history and founding journey of Clasam Schools since 1990.
    • Formal address and statement from the founder, Mrs. Clara Ahua.
  3. Contact (contact.html):
    • Comprehensive contact details (Phone numbers, campus addresses, social links).
    • Dynamic mailto: submission form pre-filling email drafts for quick user inquiries.
    • Direct link to Google Maps for campus direction navigation.

🎨 Key UI/UX Highlights

  • Custom Design Palette: Tailored color scheme inspired by the school logo (Royal Blue #1e3a8a, Accent Gold #f5a623, and Soft Teal #4a9aa8).
  • Responsive Navigation: Mobile-friendly slide-out menu drawer and hamburger toggle mechanism.
  • Interactive Animations: Intersection Observer-based fade-in scroll animations and smooth ease-out number counters.
  • Accessibility: Includes reduced motion support (prefers-reduced-motion) and structured semantic HTML elements.
