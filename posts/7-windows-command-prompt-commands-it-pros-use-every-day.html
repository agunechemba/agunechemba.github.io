Here's the updated blog post with a new opening section explaining how to open Command Prompt.

The Windows Command Prompt is still one of the fastest ways to troubleshoot, audit, and manage a PC—especially when you don’t want to click through a dozen menus. These seven commands are the kind IT professionals reach for regularly, but most everyday users have never heard of them.

Before we dive in, here’s how to open Command Prompt:

  • Quickest way: Press Win + R, type cmd, and press Enter.
  • From the Start menu: Click Start, type cmd, and select Command Prompt.
  • As administrator (recommended for some commands): Right-click the Start button and choose Command Prompt (Admin) or Windows PowerShell (Admin). Some commands—like changing passwords or running chkdsk /f—require elevated privileges.

Now, on to the commands.

1. See Every Group Policy Applied to a Computer

When something should work but doesn’t, Group Policy is often the culprit. This command builds a report showing every policy applied to the computer and user:

gpresult /R

Let it run. It will generate the report and show you exactly what’s being applied—perfect for troubleshooting mysterious configuration issues.

2. Recover a Forgotten Wi-Fi Password

If a computer has connected to a Wi-Fi network before, Windows remembers it—even if you’ve forgotten the password.

First, list every Wi-Fi profile the computer has connected to:

netsh wlan show profiles

Then show the password for a specific network by replacing Wi-FiName with the actual profile name:

netsh wlan show profile name="Wi-FiName" key=clear

Look for Key Content in the output. That’s your Wi-Fi password.

3. Check and Fix Disk Errors Before Replacing a Drive

Got a hard drive acting strange? Don’t replace it just yet. Run:

chkdsk /f

This checks the disk for errors and fixes them. It may ask you a few questions—answer them—and if the drive is in use, it can schedule the scan for the next reboot.

Sometimes the problem is simple and fixable.

4. Get a Quick Disk Health Check

Need to know whether a disk is healthy? This command shows the status of your physical drives:

wmic disk drive get status

Note: wmic is being deprecated in newer Windows versions, but for now it still works on many systems. It’s a fast way to see what’s going on with your disk.

5. See How Much RAM an Application Is Using

Ever wondered how much Chrome is really eating up? This command lists running processes by image name:

tasklist /fi "imagename eq chrome.exe"

You can replace chrome.exe with any application’s executable name. It’s a quick way to check memory usage without opening Task Manager.

6. List User Profiles and Change Passwords Quickly

Need to see which local user accounts are configured on a computer? Run:

net user

And if you need to quickly change a user’s password, use:

net user Username NewPassword

Replace Username with the account name and NewPassword with the new password. Press Enter, and it’s changed.

7. Run a Fast System Audit

Need to know what Windows version and build you’re running—or get a quick overview of the machine? Run:

systeminfo

It displays OS version, build number, processor information, RAM, and more. It’s one of the fastest ways to get the system details you need.

Final Thoughts

These commands won’t replace a full toolkit, but they’re fast, built into Windows, and incredibly useful in everyday troubleshooting. Whether you’re recovering a Wi-Fi password, checking disk health, or auditing a system, the Command Prompt can save you a lot of clicking.
